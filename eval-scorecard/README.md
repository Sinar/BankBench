# Unified Eval-Scorecard (Sinar-BankBench)

A **unified** evaluation + scorecard harness that takes the
`bankbench/3-4 LLM_scorecard` method — *run → dashboard → scorecard* — and
extends it from one eval to a **comparison across evals**. It runs
**BankBench-MY** (safety) alongside **Humanity's Last Exam** (HLE, capability)
and **Cybench** (capability, CTF) on the **same 4 models**, normalizes every
eval onto one 0–100 "higher-is-better" scale, and then grades **all three**
against the **AI Evaluation Quality scorecard** (San Joaquin, Gipiškis, Chin —
Feb 2026; see `scorecard-full-paper.md`).

> **First run = trial.** We replicate HLE and Cybench on a **20-task sample**
> each (matching BankBench's ~20-task footprint) and use the deterministic
> **mock track** by default so the dashboard always builds and the method is
> demonstrable without a GPU or API key. A **live track** (`--mode live`) runs
> real Together AI inference and is wired up but optional.

## What's here

| File | What it is |
|---|---|
| `run_eval.py` | **Run step.** Generic harness for `bankbench` / `hle` / `cybench`. Mock (default, seeded, no network) or live (Together AI). Writes `<eval>_results.json`. |
| `evals/bankbench-22-tasks.json` | Canonical BankBench-MY scenario set (reused from `Sinar-BankBench/bankbench_my/scenarios/`). |
| `evals/hle-20-tasks.json` | 20 original **representative** HLE-style tasks (trial sample — not the redistributed 3k-item benchmark). |
| `evals/cybench-20-tasks.json` | 20 original **representative** Cybench-style CTF tasks (trial sample). |
| `scorecard_assessment.json` | The 5-dimension, 1–4 grade self-assessment of each eval against the AI Evaluation Quality scorecard, with justifications. |
| `build_unified_scorecard.py` | **Dashboard + scorecard step.** Reads the three result JSONs + the assessment, renders charts, writes `unified_scorecard_dashboard.html`. |
| `bankbench_results.json`, `hle_results.json`, `cybench_results.json` | Trial outputs (regenerated by `run_eval.py`). |
| `unified_scorecard_dashboard.html` | **The unified dashboard** — models×evals matrix, per-eval breakdown, BankBench ΔADVOCACY, and the cross-eval scorecard. |

## Method (run → dashboard → scorecard)

1. **Run** — `run_eval.py` scores every (model, task, phase) and emits a
   normalized result set. BankBench is the **safety anchor** (clean-baseline
   safety pass rate, plus a Phase B compliance-forcing overlay → **ΔADVOCACY**);
   HLE is accuracy; Cybench is solve rate.
2. **Dashboard** — `build_unified_scorecard.py` puts all evals on one scale and
   draws the unified matrix + per-eval tables + charts in a single HTML page.
3. **Scorecard** — each eval is graded on the paper's five quality dimensions
   (Construct / Internal / External Validity, Reliability, Correctness), each
   scored **1 (best) … 4 (worst)**; the **Category (A–E)** is the class implied
   by the weakest dimension (a benchmark is only as strong as its weakest
   dimension — the same logic the existing `bankbench_dashboard.html` uses to
   cap BankBench at Cat D).

### Why unify them
Capability leaderboards (HLE, Cybench) and the safety benchmark (BankBench)
measure **different things**. On the trial sample a model can top HLE/Cybench
and still fail adversarial banking scenarios — so capability scores alone do
**not** certify safety. The unified scorecard makes that gap visible, and the
quality scorecard explains *why* (e.g. BankBench's pilot is N=1 per cell →
internal-validity / reliability floor items → Cat D, with a clear D→C→B path).

## Replicate the trial

```bash
cd Sinar-BankBench/eval-scorecard

# Run all three evals (mock track, deterministic, no API key) — ~seconds
python run_eval.py

# Build the unified dashboard (reads the *_results.json + scorecard_assessment.json)
python build_unified_scorecard.py
# -> open unified_scorecard_dashboard.html
```

Pick one eval, or run live:

```bash
python run_eval.py --eval hle            # just Humanity's Last Exam
python run_eval.py --eval all --mode live   # real Together AI (needs TOGETHER_API_KEY)
```

`TOGETHER_API_KEY` is read from the environment or from a `.env` at the repo
root (`technical_aisafety/.env`), mirroring `bankbench/3-4 LLM_scorecard/`.

## Caveats

- **Trial / mock.** Numbers are a deterministic seeded simulation, not empirical
  findings — clearly labelled in the dashboard. The live track is the real run.
- **Samples, not full benchmarks.** HLE/Cybench here are 20 original
  representative tasks, not the published 3k-item / repo corpora. The scorecard
  grades reflect *this trial's implementation* (hence the internal-validity /
  reliability deductions); the published benchmarks would grade higher.
- **Working draft self-assessment.** The scorecard grades are our own, following
  the paper's rubric — not an independent third-party grade (no inter-rater κ).

## Relationship to the rest of Sinar-BankBench

This folder is the **+ Scorecard** surface generalized to a *multi-eval*
comparison. It reuses BankBench-MY as the safety anchor and the
`bankbench/3-4 LLM_scorecard` run/dashboard/scorecard pipeline, and applies the
formal AI Evaluation Quality scorecard from `scorecard-full-paper.md` to every
eval it compares.
